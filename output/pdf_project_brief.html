Executive Summary

Smart Campus Space Finder è una soluzione software sviluppata nell'ambito della Python Innovation Hackathon – Challenge 1, concepita per rispondere a una delle esigenze più concrete e quotidiane della vita universitaria: sapere dove trovare un posto a sedere, uno spazio di studio o un'aula disponibile all'interno del campus.

Il progetto nasce dall'osservazione diretta di una problematica diffusa in quasi tutti gli atenei italiani: l'assenza di un sistema centralizzato, accessibile e aggiornabile in modo semplice, che permetta a studenti, docenti e personale amministrativo di conoscere la disponibilità delle aule e degli spazi comuni. Gli studenti si trovano spesso a girare per i corridoi del campus alla ricerca di un posto libero, con una perdita di tempo significativa e una fruizione inefficiente degli spazi disponibili.

La soluzione proposta si distingue per la sua semplicità architetturale e la totale assenza di dipendenze esterne: l'intero sistema è costruito utilizzando esclusivamente Python 3 con la libreria standard per il backend CLI e HTML5/CSS3/JavaScript Vanilla per il frontend web. Non è richiesto alcun server, framework, database o connessione a Internet.

Il sistema si compone di due moduli principali: una CLI Python per la gestione e l'aggiornamento dei dati e una dashboard web SPA per la visualizzazione interattiva, filtraggio e analisi dei dati. I due moduli comunicano attraverso un file JSON condiviso, rendendo il flusso operativo intuitivo e trasparente.

Il Problema

La gestione degli spazi universitari rappresenta una sfida organizzativa complessa. I problemi principali identificati durante la fase di analisi sono:

1. Mancanza di visibilità in tempo reale

Gli studenti non hanno accesso a informazioni aggiornate sulla disponibilità delle aule. I tabelloni fisici, quando presenti, sono spesso obsoleti o non aggiornati sistematicamente.

2. Dispersione delle informazioni

Le informazioni sugli orari delle lezioni, la capienza delle aule e lo stato di occupazione sono frammentate tra diverse fonti: sito web dell'ateneo, bacheche fisiche, app di terze parti, comunicazioni informali.

3. Inefficienza nell'uso degli spazi

In molti casi, aule con posti liberi rimangono inutilizzate perché gli studenti non sanno che sono disponibili, mentre zone frequentate come biblioteche risultano sovraffollate.

4. Costi di infrastruttura elevati

Le soluzioni commerciali esistenti richiedono infrastrutture server, licenze software e manutenzione continua, rendendole inaccessibili per molti atenei con budget limitati.

La Soluzione

Approccio Offline-First

Il sistema funziona completamente offline, senza necessità di connessione a Internet o server remoti. I dati sono memorizzati in un file JSON locale (data.json) che rappresenta la "fonte di verità" del sistema.

Doppia Interfaccia Complementare

  • CLI Python (main.py): Strumento per gli operatori che necessitano di aggiornare i dati in modo rapido e preciso.
  • Dashboard Web (index.html): Interfaccia visuale per gli studenti che vogliono consultare le informazioni in modo immediato.

Flusso Dati

Operatore → CLI Python → data.json ←→ Dashboard Web → Studente
Nota
La scelta di utilizzare esclusivamente la libreria standard di Python e tecnologie web native è una decisione deliberata che garantisce massima portabilità e zero dipendenze da installare.

Conclusioni

Smart Campus Space Finder dimostra che è possibile costruire una soluzione utile, funzionale e ben strutturata rispettando vincoli tecnologici severi. Il progetto raggiunge tutti gli obiettivi primari definiti nella fase di analisi e offre una base solida per evoluzioni future.

L'approccio "offline-first" con file JSON locale è una scelta consapevole che permette un'adozione immediata in qualsiasi contesto, senza requisiti infrastrutturali. Questo lo rende adatto non solo a grandi atenei, ma anche a piccole scuole e qualsiasi realtà che necessiti di gestire spazi condivisi in modo semplice ed efficace.
